## What I build

- **[agrocamping.eu](https://www.agrocamping.eu/)**: a booking website in 3 languages with its own API and payments. A working accommodation business takes its bookings here. [How it works](case-studies/agrocamping-website.md)
- **Reception panel**: the system the front desk works in: bookings, mail, WhatsApp, financial records. [How it works](case-studies/agrocamping-reception.md)
- **[polszczyzna-kontrolowana](https://github.com/maciejszulia/polszczyzna-kontrolowana)**: 32 rules that leave each Polish sentence one meaning, with a linter and a Claude skill.
- **[claude-code-skills](https://github.com/maciejszulia/claude-code-skills)**: the skills and hooks that keep my AI agents in check.
- **[neurophify](https://github.com/maciejszulia/neurophify)**: a knowledge graph in 3D, shaped like a brain.
- **[millennium-models](https://github.com/maciejszulia/millennium-models)**: minimal models of the 7 Millennium Prize problems.

The code of the first 2 systems is private. I show it live, to a person.

- **[tractatus-skills](https://github.com/maciejszulia/tractatus-skills)**: Claude Code skills that list what has to be true before an agent starts and before it reports "done".

## How I work

I write the requirements, AI agents write the code, and I accept the result on tests. Two agent sessions work as a pair: one plans and reviews, the other measures and writes code. The first 2 systems: over 2,000 commits since July 2026.
